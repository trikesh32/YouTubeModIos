# YouTubeModIos

Самостоятельный экспериментальный мод YouTube для iOS и воспроизводимый сборщик IPA.
Независимый проект, не связанный с Google или YouTube Plus. **Shorts сохраняются.**

## Текущее состояние: 0.1.3, прототип

В 0.1.2 пользователь подтвердил меню мода и фоновое воспроизведение без PiP
на iPhone в LiveContainer. Запуск, вход Google и штатный PiP также проверены
ранее. Фон по умолчанию выключен; после включения откройте видео заново.

0.1.3 переносит вход в мод в штатный список настроек: **YouTube → Настройки →
Настройки мода** (группа **YouTube Mod**). Отдельная верхняя кнопка удалена.
Новое меню ещё требует проверки на устройстве; рабочие хуки фона не изменены.
Интеграция категорий адаптирована из MIT-проекта YTKACE с проверкой ABI,
сохранением обычных категорий и предотвращением дублей. Лицензия включается
в комплект модуля и готовый IPA. Статическая проверка 14 методов прошла
на YouTube 21.46.3.

Диагностика хранится в `Documents/YouTubeMod-diagnostics.json`: статусы и счётчики
хуков, построение меню, события сворачивания/возврата и категория аудиосессии.
В ней нет аккаунтов, токенов, видео-ID или истории просмотра.

До функциональности исследованного YouTube Plus 6.0 остаются:

| Блок | Что нужно реализовать и проверить |
| --- | --- |
| Реклама | Фильтрация видео- и лентной рекламы без поломки обычных роликов и Shorts |
| SponsorBlock | Получение сегментов, категории, пропуск, отмена и обработка перемотки |
| Качество и скорость | Профили Wi-Fi/мобильной сети, сохранение выбора, кнопки плеера |
| Дизлайки | Внешний API, кеширование, корректное отображение недоступных данных |
| Скачивания | Видео/аудио, форматы, очередь, докачка, объединение дорожек и библиотека |
| Интерфейс | Настройка плеера и кадра, экспорт/импорт настроек; Shorts сохраняются |
| Выпуски | Проверки новых версий YouTube, откат, готовый источник и документация |

Наличие этих блоков в исследованном IPA установлено статически, а не проверкой
каждой функции. Порядок развития: меню → реклама/SponsorBlock → качество/дизлайки →
скачивания. Скачивания — самый крупный отдельный модуль. Задержка загрузки видео
пока не локализована и требует отдельного сравнения сети/клиента.
Подписка или активация другого мода не переносится. Закрытый YTLite не включён.

## Сборка

Нужен Mac, Python 3.11+, Clang и iPhoneOS SDK. Цель: ARM64, iOS 17+.

```sh
git clone https://github.com/trikesh32/YouTubeModIos.git
cd YouTubeModIos
./youtube-mod.command build
# Если SDK не выбран через Xcode:
# IOS_SDK_PATH=/path/to/iPhoneOS.sdk ./youtube-mod.command build
./youtube-mod.command inspect /path/to/YouTube.decrypted.ipa
./youtube-mod.command pack /path/to/YouTube.decrypted.ipa \
  --allow-untested --output /path/to/YouTubeMod-test.ipa
```

После первого build новая упаковка не требует повторной компиляции модуля.
`--kit DIR` позволяет использовать проверенный артефакт `build/kit` из GitHub Actions.
Исходный IPA не изменяется. Выходной IPA имеет техническую ad-hoc подпись;
для iPhone нужна собственная подпись через подходящий установщик.
Сохранение входа после переподписи и совместимость с AltStore пока не проверены.

Используйте собственный расшифрованный IPA исходного YouTube. Файл с YTLite/uYou
не подходит. Обычное скачивание из App Store не снимает шифрование.
Проверка известных модулей не доказывает чистое происхождение IPA.
Сборщик отказывает при изменённых обязательных ABI, зашифрованных образах,
неподдерживаемых Mach-O и опасных путях ZIP. Из поддерживаемых universal-библиотек
выбирается проверенная ARM64-секция. Совпадение ABI не гарантирует
работу на телефоне. `--allow-untested` не отключает эти проверки.
Расширения, включая виджеты, удаляются при упаковке, чтобы не требовать лишних App ID.

## Проверки и участие

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
./youtube-mod.command build
```

CI выполняет тесты упаковщика, нативные тесты ядра и сборку ARM64-модуля.
Проверка на iPhone: запуск, настройки → «Настройки мода», включение фона, новый ролик,
блокировка экрана, возвращение в приложение и проверка Shorts. Не удаляйте
рабочее приложение или аккаунт ради проверки прототипа.

В issue указывайте версию YouTube/iOS, способ подписи, сценарий и диагностику мода.
IPA, ключи, профили подписи, учётные данные и дампы чужого кода сюда не загружайте.
Публичная сборка выпускает модуль; пользовательские IPA и подписи остаются локально.
