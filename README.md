# YouTubeModIos

YouTube Mod для iOS: интеграция открытого движка [YTKACE](https://github.com/itzzace/ytkace)
с нашим сборщиком, адаптацией LiveContainer и проверенными хуками фонового воспроизведения.
Независимый проект, не связанный с Google или YouTube Plus. **Shorts сохраняются.**

## 0.2.0 — полная экспериментальная сборка

Движок YTKACE 1.1.8 закреплён на коммите `5f8cb77bbd50249d2561a129afd3bb04313568ee`.
Его исходники и лицензии находятся в `vendor/ytkace`; изменения интеграции применяются
в `scripts/build_full.py`. Это интеграция существующего MIT-проекта, не разработка всех
перечисленных функций с нуля. Спасибо itzzace и остальным авторам компонентов.

**На устройстве весь набор 0.2.0 ещё не проверен.** На 0.1.2 пользователь подтвердил
вход Google, штатный PiP, меню и фон без PiP в LiveContainer. Эти результаты не заменяют
проверку новой полной сборки. Целевая версия YouTube для первого теста — **21.46.3**.

| Включено в сборку | Состояние по умолчанию / проверка |
| --- | --- |
| Удаление видео- и лентной рекламы | Включено; проверить обычные видео и Shorts |
| SponsorBlock | Включён; категории и режим пропуска настраиваются |
| Return YouTube Dislike | Показ включён; отправка голосов выключена |
| Качество и скорость | Кнопки включены; доступны предпочтения Wi-Fi/сотовой сети |
| Видео- и аудиоскачивания | Включены; очередь, библиотека, объединение дорожек FFmpeg |
| Скачивание плейлистов | Включено; требуется проверка на коротком плейлисте |
| Фон и PiP | Прежний выбор фона переносится; дополнительный PiP-хук выключен, штатный PiP остаётся |
| Очередь, повторы, таймер сна, жесты | Доступны настройки; дополнительные режимы включаются по выбору |
| Настройка интерфейса, DeArrow, фильтры | Доступны; не все включены по умолчанию |
| Резервная копия/восстановление | Настройки и библиотека через раздел скачиваний |
| Shorts | Раздел и ролики не скрываются по умолчанию |

Вход: **YouTube → Настройки → группа YouTube Mod → Настройки мода**.
Отдельной верхней кнопки «Мод» нет. Внутренние страницы могут сохранять название
и версию YTKACE — это версия движка, а не версия нашей интеграции.

В LiveContainer обновляйте существующий YouTube импортом IPA через «+»; не удаляйте
приложение или аккаунт ради проверки. Перед обновлением сохраните рабочий IPA.
В 0.2.0 собственные хуки идентификации YTKACE не устанавливаются в LiveContainer:
контейнер продолжает обслуживать вход. Обычная установка подписанного IPA требует
отдельной проверки. Нет гарантии совместимости с каждой новой версией YouTube.

## Сборка

Нужен Mac, Python 3.11+, Clang, make и iPhoneOS SDK. Цель: ARM64, iOS 17+.
Первый build скачивает закреплённые исходники FFmpeg и собирает их локально без
GPL/nonfree-компонентов. Готовые чужие статические библиотеки не используются.

```sh
git clone https://github.com/trikesh32/YouTubeModIos.git
cd YouTubeModIos
# Для предварительной 0.2.0: git checkout feature/0.2.0-full
./youtube-mod.command build
# Если SDK не выбран через Xcode:
# IOS_SDK_PATH=/path/to/iPhoneOS.sdk ./youtube-mod.command build
./youtube-mod.command inspect /path/to/YouTube.decrypted.ipa
./youtube-mod.command pack /path/to/YouTube.decrypted.ipa \
  --allow-untested --output /path/to/YouTubeMod-test.ipa
```

После build повторная упаковка не требует компиляции. `--kit DIR` принимает
комплект из `build/kit`. Комплект включает ресурсы, лицензии и `relink/` с точными
исходниками FFmpeg, объектами и инструкцией замены LGPL-библиотек. Хэши закреплены.
Исходный IPA не меняется; техническая ad-hoc подпись требует переподписи установщиком
либо обработки LiveContainer. Публично распространяем исходники и комплект мода;
проприетарные IPA YouTube, профили подписи и аккаунты в репозиторий не входят.

Нужен собственный расшифрованный IPA исходного YouTube. Обычная загрузка App Store
не снимает шифрование; сборка с YTLite/uYou не подходит. Сборщик отвергает известные
чужие модули, опасные ZIP-пути, зашифрованные образы и несовместимые обязательные ABI.
Проверяются **14 выбранных методов**, а не каждый хук полного движка. Совпадение ABI
не доказывает чистое происхождение IPA или работоспособность всех функций.
Расширения/виджеты удаляются, чтобы не требовать лишних App ID.

## Проверки

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 -m unittest discover -s vendor/ytkace/Tests -p 'test_*.py'
./youtube-mod.command build
```

Проверяются упаковка, ресурсы и хэши, поведение базовых хуков, миграция предпочтений,
общий переключатель, сохранение Shorts и компиляция полного ARM64-модуля.
Тесты `NativeMenuTests` относятся к прежней реализации 0.1.3: они не доказывают
работоспособность нового меню YTKACE. Сам 0.1.3 IPA снят с локального тестирования.

Первый тест 0.2.0: запуск и сохранённый аккаунт → штатное меню → обычный ролик →
фон/блокировка экрана → Shorts → SponsorBlock на ролике с известными сегментами →
качество/скорость → одно короткое скачивание видео и аудио → воспроизведение из
библиотеки. Полный набор пока не объявляется стабильным релизом.

## Данные и лицензии

SponsorBlock/DeArrow и Return YouTube Dislike обращаются к внешним API с видео-ID;
эти функции можно отключить. Отправка голосов RYD по умолчанию выключена.
Встроенная диагностика `Documents/YouTubeMod-diagnostics.json` содержит версии,
счётчики фоновых хуков и состояние аудиосессии. Движок отдельно ведёт журналы
скачиваний: перед публикацией таких журналов проверьте их содержимое.
Импорт резервной копии ограничен ключами настроек мода `YTKACE.Preference.*`.

Код интеграции и YTKACE — MIT; FFmpeg — LGPL; данные внешних сервисов имеют
отдельные условия. См. [PROVENANCE.txt](PROVENANCE.txt), [уведомления компонентов](vendor/ytkace/THIRD_PARTY_NOTICES.md).
Закрытый код YTLite/YouTube Plus и обход его активации не включены.
